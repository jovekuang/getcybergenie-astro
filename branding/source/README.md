# Approved Cyber Genie master

Selected C7: friendly winking genie, thumbs-up, relaxed other arm, curled tail. No Wi-Fi symbol, chest emblem, floating icon, or background.

The original SVG contains real paths and transparent interiors. The original PNG has an alpha channel. They are retained as the source of truth; production assets are generated by `npm run assets:brand` without changing the paths. The script trims surrounding whitespace and creates monochrome, reversed, icon and wordmark assets.

Any future pose must preserve the same face, head curl, ears, tail, proportions and outline style. New poses are optional and were not substituted for the approved master in this first release.
